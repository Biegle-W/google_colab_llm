# Unsloth Studio on Google Colab

Runs the official [Unsloth Studio](https://github.com/unslothai/unsloth/tree/main/studio) notebook on a free Colab **T4** GPU.

## Usage
1. Open `studio/Unsloth_Studio_Colab.ipynb` in Colab (use the badge at the top of the notebook).
2. Runtime → Change runtime type → **T4 GPU**, then Runtime → **Run all**.
3. Open the Cloudflare link printed by the last cell and log in with the admin credentials it shows.
